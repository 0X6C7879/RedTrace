## 二、业界经典案例（乌云）

### 案例1：淘客帝国CMS任意文件读取
**厂商**: 淘客帝国CMS | **类型**: 任意文件读取（url参数路径穿越）

**洞察**: CMS的url参数直接作为文件路径读取，未做路径限制，可读取服务器任意文件包括配置文件和源代码

**测试流程**:
1. 发现url参数控制文件路径
2. 尝试../路径穿越
3. 读取/etc/passwd确认漏洞
4. 读取配置文件获取数据库凭证

**技术细节**:
taodiv6free_install，url参数未过滤路径穿越，利用ORIG_PATH_INFO实现任意文件读取

**POC示例**:
```http
GET /read.php?url=../../../etc/passwd HTTP/1.1
GET /read.php?url=../../../../var/www/html/config.php HTTP/1.1
```

**绕过技巧**: 直接../穿越，无过滤

**修复建议**: 使用realpath()规范化路径，验证规范化后的路径以允许的目录为前缀

### 案例2：某安防厂商某视频接入网关系统通用型任意文件遍历下载（大量设备）
**厂商**: 某安防厂商 | **类型**: 任意文件遍历/下载（通用型）

**洞察**: 安防摄像头网关系统的文件下载接口无认证且存在路径穿越，大量同型号设备均受影响，是典型的通用漏洞

**测试流程**:
1. 访问网关HTTP接口
2. 发现文件下载接口（无认证）
3. 使用../穿越读取系统文件
4. 批量利用影响大量同型号设备

**技术细节**:
无需登录的文件下载接口，存在路径穿越，大量安防设备通用受影响

**POC示例**:
```http
GET /download?file=../../../etc/passwd HTTP/1.1
# 无需认证
```

**绕过技巧**: 无认证无需绕过

**修复建议**: 文件下载接口强制认证，路径白名单验证，限制可下载文件目录

### 案例4：深度上网行为管理设备敏感文件下载（可成功控制设备）

**POC示例**:
```http
GET /getcfgfile HTTP/1.1
```

### 案例5：siteserver某子站存在目录遍历漏洞（RelatedPath参数）
**厂商**: SiteServer CMS | **类型**: 目录遍历（RelatedPath参数）

**洞察**: CMS文件管理功能的RelatedPath参数可指定任意服务器路径，实现目录遍历和文件列表获取

**测试流程**:
1. 访问文件管理页面
2. 修改RelatedPath参数为/d:/wwwroot/
3. 获取服务器文件列表
4. 逐步遍历发现敏感文件

**技术细节**:
/form/filemanagement.aspx?RelatedPath=/d:/wwwroot/ 可遍历服务器目录

**POC示例**:
```http
GET /form/filemanagement.aspx?RelatedPath=/d:/wwwroot/ HTTP/1.1
GET /form/filemanagement.aspx?RelatedPath=/../../../etc/ HTTP/1.1
```

**绕过技巧**: Windows路径：/d:/直接访问绝对路径绕过相对路径限制

**修复建议**: 禁止绝对路径和路径穿越，文件管理限定在允许目录内

3. 在path参数中使用../穿越


**绕过技巧**: URL编码%2f%2e绕过简单../过滤

## 三、方法论总结

### 3.1 高频参数统计

| 参数名 | 出现频次 | 说明 |
|--------|----------|------|
| `file` / `filename` | 4次 | 最常见的文件路径参数，直接控制下载文件 |
| `path` / `filePath` | 3次 | OA/CRM系统高发参数，控制文件读取路径 |
| `url` / `urlParam` | 2次 | CMS和云平台中以URL形式传递的文件路径 |
| `RelatedPath` / `dirget` | 各1次 | 目录遍历场景的专用参数 |
| `Accessory` | 1次 | 教育CMS通用下载参数 |
| `Vis1` / `Vis2` / `Vis3` | 1次（多参数） | OA系统中分拆传递的路径参数 |
| `opt` + `userid` | 1次（组合） | 邮件系统中操作类型+用户双参数控制文件路径 |

### 3.2 攻击模式分布

| 攻击模式 | 案例数量 | 典型代表 |
|----------|----------|----------|
| 单参数路径穿越（../直接读取） | 5个 | 淘客帝国CMS、华云数据、Winmail Server、悟空CRM、教育CMS |
| 无认证文件下载 | 3个 | 安防网关、Winmail Server、深度上网设备备份 |
| 目录遍历（列目录+浏览） | 3个 | SiteServer CMS、中钢OA、Yxcms后台 |
| Windows绝对路径绕过 | 1个 | SiteServer CMS（/d:/wwwroot/） |
| 多参数组合利用 | 1个 | 中钢集团OA（Vis1/Vis2/Vis3/filePath） |
| 遍历+删除（破坏性攻击） | 1个 | Yxcms旁站攻击 |
| 设备通用漏洞（批量影响） | 2个 | 安防网关、深度上网设备 |
| 登录后低权限穿越 | 1个 | 悟空CRM |

### 3.3 关键检测信号

**接口特征**:
- 文件下载接口参数含有路径分隔符相关字符（`/`、`\`、`.`）
- 参数名为 `file`、`path`、`filename`、`url`、`Accessory` 等语义明确的文件路径参数
- 无认证的文件下载/读取接口（直接GET可访问）
- CMS/OA系统的文件管理模块参数中传入目录路径

**响应特征**:
- 响应体包含 `/etc/passwd`、`root:x:0:0:` 等 Unix 系统文件内容
- 响应体包含 `[boot loader]`、`[operating systems]` 等 Windows 系统文件内容
- 响应体包含源代码文件关键字（`<?php`、`import`、`password=` 等）
- 文件下载响应的 `Content-Disposition` 头携带敏感文件名

**代码审计信号**:
- 文件读取前未调用 `realpath()` / `filepath.Clean()` / `os.path.realpath()` 规范化路径
- 规范化后未校验路径前缀是否在允许目录内
- 使用 `contains("..")` 黑名单过滤而非白名单校验（可被 URL 编码绕过）
- 文件下载接口缺少身份认证注解/中间件

### 3.4 常见绕过技巧

| 绕过技巧 | 适用场景 | 原理与要点 |
|----------|----------|------------|
| URL编码（`%2e%2e%2f`） | 简单`../`字符串过滤 | 服务端解码后还原为`../`，绕过对明文`../`的黑名单检测 |
| 双重URL编码（`%252e%252e%252f`） | 单次解码后过滤 | 需服务端或框架进行二次解码时有效 |
| Unicode/UTF-8编码（`..%c0%af`） | Java/旧版服务器 | 利用宽字节或非标准UTF-8编码绕过路径过滤 |
| Windows绝对路径（`/d:/`） | 相对路径限制场景 | 直接使用盘符绝对路径绕过仅针对`../`的过滤 |
| 路径截断（`%00`） | 旧版PHP文件读取 | 空字节截断文件后缀限制（PHP 5.3以前） |
| 多参数分拆传递 | 单参数过滤场景 | 将路径分段存入不同参数，服务端拼接后产生穿越 |
| 旁站利用（共享文件系统） | CMS多站点部署 | 登录旁站后台，利用共享磁盘路径访问主站文件 |
| 无认证接口直接利用 | 未鉴权文件下载 | 无需任何绕过，直接构造路径穿越请求 |
