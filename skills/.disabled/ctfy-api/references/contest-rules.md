# CCF-TPCTF 2026 官方规则 v2.6 摘要

> **历史快照，不是 CTFy 通用约束。** 当前赛期、容量、网络和模型要求以所选比赛的实时公告与字段为准。
> 来源为用户上传的 `CCF-TPCTF赛事规则手册-v2.6.pdf`（2026-11-13）；如平台发布新公告，应以最新公告为准。

## 智能体赛道

- **11 月 14 日 10:00–15:00（北京时间）**：入围赛。Agent 自行部署在本地，测试解题 Agent 和出题 Agent 的基本功能、执行和平台交互；按经核验**解题成绩**排名，前 150 晋级，成绩并列按最后一次解题时间决定次序；入围赛成绩计入初选赛。
- **11 月 15 日 10:00–20:00**：初选赛。Agent 运行在主办方分配的独立 VPS；限制公网。前 30 晋级正式赛，初选赛解题成绩占综合解题成绩 50%。
- **11 月 21 日出题**：三轮分别 10:00–12:00、14:00–16:00、18:00–20:00；每轮下发主题，每队每轮最多提交一道符合要求的新题，经过自动验题和审核；Web、Pwn、AI Security 类，其他类别不接受。不同轮不得重复提交同一题。
- **11 月 22 日 10:00–20:00 解题**：晋级队伍的解题 Agent 自主解答已审核赛题。不能从本队出题中获分。出题分与综合解题分按规则各占最终 50%。

## 模型、网络、自动化

- 入围赛：《参赛接口文档》8.1 节明确本地 Agent **不需经过主办方模型网关**、使用队伍自有 Key。规则手册“可通过网关”的表述与接口文档细节有差异；以官方平台当前公告为准。
- 初选赛：只能通过平台网关访问官方白名单模型，使用队伍自有 Key；不得绕过网关从 VPS 直连厂商。
- 正式赛：只能通过平台网关使用主办方提供的智谱模型，总 Token 限额 1B。
- 解题 Agent 没有任意公网访问权限；可访问授权平台接口、大模型网关、题目入口；工具/依赖须预装，不得使用代理、子进程等绕过网络规则。
- 智能体出题/解题必须**自主完成**；正式任务期间不能人工注入赛题分析、指令、代码、答案；允许平台指定的状态查看、启停和故障申报。
- 只能攻击官方授权题目，不得攻击基础设施、其他队伍或外部系统，不能暴力破解 Flag 提交接口。
- Agent 运行记录和比赛材料需要按平台规定留存供核验。
