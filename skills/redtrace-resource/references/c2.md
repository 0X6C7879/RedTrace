# C2 Reference

Listener、Session、Payload 都是 Resource（`kind: c2_listener` / `c2_session` / `c2_payload`），由 Resource registry 统一登记、共享和审计。

## 相关命令

- `redtrace-resource listener-create` — 创建 Listener（TCP reverse / TCP bind；`--listener-type` 可选 http_beacon、https_beacon、external_c2 等）
- `redtrace-resource session-register` — 登记 shell session（`--connection-type` 支持 direct / reverse / bind / external_c2）
- `redtrace-resource payload-oneliner` — 生成一行 payload
- `redtrace-resource payload-build` — 构建 Beacon
- `redtrace-resource payload-external` — MSF/Sliver/Cobalt Strike 适配
- `redtrace-resource payload-import` — 导入 Worker 生成的 payload
- `redtrace-resource list --kind c2_session` — 查看已有 session

## 典型流程

1. 需要 shell 时先 `list --kind c2_session` 查看是否已有可复用 session
2. 需要 Listener 时创建后从返回的连接信息接收 session
3. 拿到 session / 起好 Listener 后立即用对应子命令（`session-register` / 已由 `listener-create` 登记）注册，趁通道在线
4. 详细参数或失败原因查看各子命令 `--help`，修正参数重试；是否继续由你判断

注册是新通道的默认动作——其他 Worker 靠它发现和复用通道。
