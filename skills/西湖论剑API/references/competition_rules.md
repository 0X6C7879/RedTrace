## 平台地址及账号密码

- **平台地址**：`gcsis.dasctf.com`
- **账号**：中文姓名 + 手机号后四位（如 `张三1234`），或手机号
- **密码**：`Das#` + 身份证后四位（若末位为 X 则大写，如 `Das#123X`）

## flag 格式

- flag 格式为 `DASCTF{}` 或 `flag{}`
- **提交时仅需提交 `{}` 内内容**，不需要提交完整格式
- 若有特殊格式要求将在题目内注明

## 提交限制

- **每题 flag 最大提交次数为 50 次**，超过 50 次将无法提交
- 禁止对赛题 flag 进行爆破，违规者一律取消比赛成绩

## 计分规则

- 积分方式为**递减模式**
- 每道题根据难度设置不同初始分值
- 题目分数随解题人数增加逐步减少，下降幅度为初始分数的 1%
- **题目最低分数为初始分数的 80%**
- 示例：题目 A 初始 200 分 → 第 1 人答出得 200 分 → 第 2 名 198 分 → … → 第 20 名及以后 160 分

## 排名规则

- 按分数高低进行实时排名
- 分数相同情况下以时间先后排序（先答出者排名靠前）

## 放题规则

- 赛题将根据赛程情况**分批放题**，请注意平台公告

## Agent 接入限制

- 每支队伍仅允许**一个 Agent** 接入平台进行答题
- 智能体必须接入平台提供的大模型网关
- 所有通信必须经由授权 API 端点白名单
- 后期将做流量审计，未通过大模型网关做题将取消比赛成绩

## 违规行为与处罚

以下行为触发设备告警，一经确认立即取消涉事队伍全部比赛资格：

- 使用任何未经授权的大模型服务
- 任何试图突破网络隔离或干扰监控系统的行为

## 注意事项

1. 参赛者必须使用本人账号登录平台，获取团队 accesskey 进行答题
2. 赛事期间禁止选手及 Agent 通过各种途径与他人进行通信或互动
3. 禁止对赛题 flag 进行爆破
4. 赛事采取严格的反作弊监控机制
5. **比赛结束前需在线提交解题报告**，专家委员会将对解题报告和网络流量、平台日志进行事后分析审核，审核通过后成绩方为有效
6. 未提交解题报告或解题报告与网络流量/平台日志不吻合的选手将被取消获奖资格
7. 比赛结束后 Agent 获得的 flag 将无法在平台及 API 提交
