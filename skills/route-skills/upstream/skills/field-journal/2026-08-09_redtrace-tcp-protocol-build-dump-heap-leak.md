# TCP协议服务 BUILD/DUMP 堆内存泄露

## 场景
TCP行协议服务提供BUILD/DUMP/EXPORT类命令，用于构造并输出内部数据结构（如HTTP响应）。当这些命令输出内部缓冲区时，未初始化的内存区域可能泄露相邻堆数据。

## 利用模式
1. 连接到TCP行协议服务
2. 使用ADD/SET类命令构造内部状态（如添加header、设置body）
3. 调用BUILD/DUMP/EXPORT命令输出完整结构
4. 检查输出中是否包含未初始化区域（常见标志：大量NUL字节后跟可读字符串）

## 具体发现
某TCP响应构造服务在BUILD输出中暴露了`hdrtab:`字段，该字段打印header table原始内存区域，其中包括相邻堆块中预加载的敏感数据（flag、密钥等）。利用仅需ADDHEADER + SETBODY + BUILD三步即可触发泄露。

## 适用条件
- TCP行协议或类似请求-响应协议的服务
- 存在BUILD/DUMP/EXPORT/PREVIEW等构造+输出类命令
- 输出中包含内部缓冲区的原始字节或结构化dump

## 检测方法
- 先用正常输入构造状态并BUILD，观察输出格式
- 在输出中搜索ASCII可打印字符串（flag、key、secret、password等）
- 变化输入大小（body长度、header数量）观察泄露区域变化
- 对比不同输入下泄露内容的一致性（判断是否为堆残留而非当前分配）

## 限制
- 依赖flag/密钥在进程启动时被加载到堆中，且位于输出缓冲区附近
- 不同的堆分配顺序和大小可能影响泄露成功率
- 如果输出缓冲区在分配后被memset清零，则无法泄露
