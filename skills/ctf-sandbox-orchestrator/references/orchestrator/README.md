# Competition Profile Rules

This directory documents the shared operating model injected by the
`competition` Skill Profile. It is not a Skill router and does not select or
invoke child Skills.

The profile treats challenge targets and artifacts as sandbox fixtures,
prefers passive inspection, proves one minimal end-to-end path before
expanding, and keeps conclusions tied to reproducible evidence. Capability
resolution selects ordinary Skills and matching `competition-*` Skills before
an Explore session starts.

Use the domain-specific reference file that matches the active Capability.
Do not bulk-load unrelated references or use this document as a prerequisite
for a child Skill.
