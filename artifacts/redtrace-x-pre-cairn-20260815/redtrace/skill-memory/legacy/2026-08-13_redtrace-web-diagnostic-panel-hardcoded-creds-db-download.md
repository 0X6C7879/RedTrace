# 系统诊断面板类 Web 题速解模式

## 场景
Web 诊断面板/管理后台登录页，描述暗示「超管密码硬编码」。

## 关键路径
1. 前端 JS（如 js/login.js）中查找 `atob('...')` 或注释里的测试凭据——超管密码常以 base64 混淆硬编码。
2. 登录后若面板页（dashboard）为空/损坏，直接枚举 `/db/*.db`、`/db/*.sqlite`（应用名.db）等数据库文件，可能未受目录保护而直接下载。
3. 用 `strings` / sqlite3 直接读 `config` 表，flag 常以 `system_flag` 键明文存放，无需登录绕过或 SQLi。

## 要点
- 目录 `/db/` 返回 403 仅禁止列表，内部已知文件名仍可 200 下载。
- 先用应用名/产品名拼接猜 DB 文件名（sysdiag.db、app.db 等）。
- 密码 base64 混淆仅为前端「安全」，直接解码即可。
