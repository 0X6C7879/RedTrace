## 数据来源

报告内容基于以下脚本输出：

| 内容 | 来源脚本 |
|------|----------|
| 错误案例列表 | `query_benchmark.py --type FP/FN` |
| 推理过程 | `session_parser.py --types llm_reasoning` |
| 根因判定 | `classify_error.py --format text` |
| 统计指标 | `stats_summary.py --by-vul-type` |

---

## 质量要求

- 典型案例数 >= min(2, FP+FN)
- 每个案例包含代码证据
- 改进建议可追溯到具体根因
- 包含回归测试清单
